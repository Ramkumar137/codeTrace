                      Your model passed the test. But was the test trustworthy?
                      
        
                      Machine-learning results can look convincing while the evaluation process quietly reuses training data, fits transformations using held-out examples, or carries information from the target into the features. These mistakes can inflate scores and make a model less reliable when it meets new data.
                      
        
                      
          
                      Follow the evidence through the notebook
                      
          
                      CodeTrace inspects notebook source without running it. It identifies recognizable data-loading, preprocessing, split, model, prediction, and evaluation calls, then connects operations when source code shows shared variable references. Each extracted operation points back to its cell and line so you can inspect the original context.
                      
        
                      
        
                      
          
                      Trace, audit, and review
                      
          
                      The pipeline trace is a compact, X-Ray-inspired view of the workflow that can be supported by static source. The audit flags a limited set of recognizable patterns, with evidence, confidence definitions, and practical review guidance. The evidence report preserves those findings and their source references for reproducibility and discussion.
                      
          
                      Current checks are deliberately narrow: they can flag test-named variables passed to fitting, training-named variables passed to evaluation, and common preprocessing fits that appear before a later split. A flagged pattern is a potential risk, not a confirmed defect.
                      
        
                      
        
                      
          
                      Interpret with care
                      
          
                      Static analysis cannot establish every runtime fact. Variable names and source order may not reflect actual data contents or execution order; dynamic code, aliases, hidden state, and dataset contents may be outside the analyzer’s reach. CodeTrace does not load referenced paths or URLs, execute notebook cells, or prove that a dataset was loaded or a model was trained.
